Presets
Key settings greatest effect on the result
Max. vertices per shape8
Maximum points in one color region's outline. 3–4 creates coarse, angular shapes; higher values follow the real outline more accurately.
Color sensitivity30%
Low values merge the image into a few large color regions. High values distinguish subtle shades, creating more small regions and more accurate colors.
Gradient and texture smoothing35%
Smooth gradients and fine-grained textures such as skies, light rays, and noise can otherwise split into thousands of tiny polygons. This gently blurs them before color classification so they merge into larger surfaces while preserving real sharp edges. 0% disables it; higher values reduce micro-shapes in flat or noisy areas.
Size tolerance50%
Large regions can receive up to 8× more vertices than small ones, preserving their outline instead of simplifying them as aggressively as tiny shapes.
Merge nearby vertices px
Similar to Blender's Merge by Distance: vertices closer than this distance become one averaged point. This reduces vertex count and file size without visibly changing the outer shape. Shared borders stay gap-free. 0 disables it; the number field also accepts values beyond the slider range.
Edge sharpening0%
Increases contrast at polygon boundaries with an unsharp mask. 0% leaves the image unchanged; higher values look sharper but may add grain.
Advanced settings
Small-shape and text detail0%
Adds vertices to small but visually complex shapes such as text, thin lines, and sharp details. Large regions and already smooth small shapes are left alone, so detail is added only where needed.
Tiny-shape removal threshold px²
Regions below this area merge with a similarly colored neighbor at pixel level before outlines are drawn. Decimal values such as 0.05, 0.2, or 0.7 px² allow fine control; the number field accepts values beyond the slider range.
Removal color tolerance
Controls how different a tiny shape may be from its neighbor and still merge. Low values preserve eyes, highlights, and text; high values also remove strongly contrasting tiny shapes. The number field accepts values beyond the slider range.
Preserve holes inside shapes
When disabled, fewer polygons are needed, but objects with holes—such as the letter O or a wheel rim—are rendered solid.
Color background resolution px
Embeds a small, heavily compressed version of the original beneath the polygons. It supplies an approximate source color where tiny-shape removal leaves a gap. Higher values improve those colors but increase both .pvec and .svg file size.
