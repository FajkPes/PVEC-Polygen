# PVEC Polygen

A browser tool for turning images into stylized polygon artwork.

## Key features

- Adjust detail, smoothing and shape controls.
- Preview the mesh and compare it with the original.
- Export SVG, PNG or the compact PVEC format.

## Get started

Download the ZIP from Releases and open `index.html`. Images are processed locally.
